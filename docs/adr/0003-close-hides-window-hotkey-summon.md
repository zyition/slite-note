# 关闭 = 隐藏，全局热键与托盘唤起

极简便签的驻留形态：顶栏关闭按钮调用 `Window.Hide()` 而非退出，应用保持后台运行；`Alt+Shift+S` 全局热键与托盘"显示/隐藏"菜单项切换窗口可见性；托盘"退出"是唯一的退出路径（窗口为无边框，无系统关闭按钮可依赖）。热键注册依赖 ADR-0001 的 Wails v3 内置 GlobalShortcut（Win32 RegisterHotKey，系统级）。用户明确此为"核心功能"。

**Consequences**
- 应用长期驻留进程（内存占用约 WebView2 一个页面），符合便签常驻心智。
- 退出路径隐藏较深（仅托盘），MVP 接受；设置页迭代时考虑加入退出入口。
